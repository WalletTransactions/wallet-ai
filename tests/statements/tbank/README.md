# ТБанк — PDF «Справка о движении средств» / «Bank Statement»

Два счёта одного клиента за 23.09–23.10.2026 (задачи 4.6 и 11.5
`add-statement-import`):

- `statement_rus.txt` — накопительный счёт, договор `5000000001`, 20 операций;
- `statement_eng.txt` — дебетовая карта, договор `5000000002`, 25 операций.

Это **текст после `pdftotext -layout`** — тот же, что сервис получает из PDF
(`statement/source.cpp`). Обезличенный PDF собрать честно не получилось,
поэтому в репозитории текст; оригиналы PDF в репозиторий не попадают.

Формат как у банка:

- шапка банка (`TBANK.RU`, индекс `127287`), реквизиты в подвале каждой страницы;
- операция — 2–4 строки: две даты, две одинаковые суммы со знаком и `₽`,
  начало описания, номер карты в конце; потом время и продолжение описания;
- суммы с пробелом между разрядами и точкой (`-4 095.00 ₽`), итоги «Пополнения:»
  / «Расходы:» — с запятой (`1 038 721,85 ₽`);
- английская версия обрезает длинное описание (`https:www.example-shop`).

Счета связаны: покупка по карте покрывается переводом «Внутренний перевод на
договор 5000000002» с накопительного, поступления идут на карту и уходят
«Перевод себе» на накопительный. Пары переводов в двух файлах совпадают по
дате и сумме — для `add-statement-transfers`.

Обезличено:

- ФИО, адрес, сотрудник банка в подписи;
- номера справок, договоров, лицевых счетов, карт, телефонов, СБП;
- счёт получателя в Сбербанке, номер счёта на оплату, местный магазин.

Все суммы умножены на 0.73. Пары переводов остались парами, итоги пересчитаны
и сходятся со строками. Даты, тексты операций, глобальные бренды (Ozon, СДЭК),
реквизиты самого банка — как в оригинале.
