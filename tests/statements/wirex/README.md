# Wirex — CSV-выгрузка EUR-счёта

`statement_eur.csv` — обезличенная выгрузка из приложения Wirex за
01.08–30.09.2026, 106 операций (задача 4.6 `add-statement-import`).

Формат сохранён как у банка:

- кодировка **UTF-16LE без BOM**, строки через CRLF, разделитель `;`, `;` в
  конце каждой строки;
- колонки `Completed Date;Type;Description;Amount;Account Currency;Rate;Foreign Amount;Foreign Currency;Balance;Related Entity ID`;
- дата `ДД-ММ-ГГГГ ЧЧ:ММ:СС`; сумма со знаком, **без хвостовых нулей**
  (`-31`, `-76.1`, `-2.67`), точка — разделитель; последняя числовая колонка —
  остаток;
- `Type`: `Card Payment` (покупка; плюс — возврат), `Fee`, `Exchange` (обмен
  EUR ↔ EUROC/GBP внутри Wirex), `Money Sent`, `Bank Transfer`,
  `ATM Withdrawal`;
- `Description` покупки — `Card NNNN : ПРОДАВЕЦ,ГОРОД,СТРАНА`.

Обезличено: суммы (тот же вид числа, колонка `Balance` пересчитана и
сходится), местные магазины и адреса, города, последние цифры карт, имя
получателя перевода. Даты, время, типы операций, глобальные бренды (Temu,
Glovo, Lukoil, Dodo Pizza), курс и иностранная сумма обменов — как в
оригинале по смыслу. Оригинал в репозиторий не попадает.
