# Proposal

## Why

Пользователь хочет спрашивать про свои деньги обычными словами («сколько за
няню», «чем сентябрь отличается от августа») из Telegram, а позже из веба,
и выбирать, какой ИИ отвечает: локальная LM Studio, Claude или в будущем
своя модель. Пункт #8 плана (`org/docs/TODO_wallet_ai.md`, задание `chat`)
этого ещё не умеет.

Инструменты чтения кошелька уже есть в wallet-mcp, и LM Studio через него
отвечает правильно (проверено 2026-11-02). Не хватает серверного агентного
цикла, который работает с любым провайдером и не отдаёт провайдеру ни
токены, ни доступ к сервисам.

## What Changes

- Новый вид задания `chat` в `POST /api/ai/jobs`: вопрос, необязательный
  `conversation_id` → текст ответа. Ответ собирается агентным циклом:
  модель просит инструменты, wallet-ai исполняет их через wallet-mcp и
  возвращает результаты модели (не больше 5 шагов, дедлайн задания).
- wallet-ai становится MCP-клиентом wallet-mcp (`initialize`, `tools/list`,
  `tools/call`) по внутренней сети. Провайдер получает только схемы
  инструментов и их результаты. Токены и адреса сервисов он не видит.
- Токен для wallet-mcp wallet-ai получает обменом JWT пользователя в
  google-auth (`/internal/token/exchange`, actor `wallet-ai`). Обмен
  выполняется при создании задания.
- Провайдеры:
  - `lmstudio` — OpenAI-совместимый `chat/completions` с `tools`
    (тот же `LLM_URL`, тот же адаптер подойдёт своей модели);
  - `claude` — Anthropic Messages API с `tools`.
- Настройки ИИ пользователя: `GET/PUT /api/ai/settings`. Это выбранный
  провайдер, список доступных провайдеров и согласие на передачу данных в
  облачного провайдера. Хранятся в базе ai.
- Claude по варианту (a): ключ `ANTHROPIC_API_KEY` один на стек, доступ по
  списку пользователей `ANTHROPIC_ALLOWED_USERS`, выбор только после
  согласия. Заложены швы под собственный ключ пользователя (вариант b):
  - ключ определяется на каждый вызов;
  - в ошибках провайдера различается, чей ключ отказал;
  - учёт токенов ведётся по пользователю и провайдеру.
- Очередь по провайдерам: облачные задания выполняет свой пул воркеров и не
  ждут GPU. `parse_expense` и чат через LM Studio работают как раньше.
- История диалога в памяти: последние реплики по `conversation_id`,
  30 минут. Так модель может переспросить («за какой месяц?»), а
  пользователь — ответить.
- Новый промпт `prompts/chat.txt` с версией.

## Capabilities

### New Capabilities

- `ai-chat`: задание `chat` — вход и результат, агентный цикл и его пределы,
  исполнение инструментов через wallet-mcp, история диалога, приватность.
- `ai-providers`: провайдеры моделей, их доступность, настройки и согласие
  пользователя, выбор ключа на вызов, ошибки и учёт по провайдеру.

### Modified Capabilities

- `ai-jobs`:
  - `kind` может быть `chat`;
  - отказ «ИИ выключен» проверяется по провайдеру задания;
  - очередь и воркеры разделены на локальную и облачную полосы.

## Impact

- **Код:**
  - новые: `src/chat.{hpp,cpp}` (цикл), `src/chat_models.{hpp,cpp}`
    (адаптеры OpenAI/Anthropic), `src/mcp_client.{hpp,cpp}`,
    `src/providers.{hpp,cpp}` (реестр, настройки, ключи),
    `src/auth_exchange.{hpp,cpp}`;
  - изменения: `src/jobs.{hpp,cpp}` (полосы), `src/ai.cpp` (вид `chat`,
    `/api/ai/settings`), `src/main.cpp` (конфиг).
- **БД:** миграция `000002_ai_user_settings` (база ai). Без `DATABASE_URL`
  провайдер всегда по умолчанию, `PUT` настроек — `503`.
- **API:** `openapi.yaml` (вход и результат `chat`, `/api/ai/settings`),
  `README.md`.
- **Конфиг:**
  - сервисы: `WALLET_MCP_URL`, `AUTH_EXCHANGE_SECRET`;
  - Claude: `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`, `ANTHROPIC_ALLOWED_USERS`,
    `ANTHROPIC_EFFORT`;
  - очереди: `AI_DEFAULT_PROVIDER`, `AI_CLOUD_MAX_CONCURRENT`;
  - чат: `AI_JOB_TIMEOUT_SECS_CHAT`, `AI_CHAT_MAX_STEPS`,
    `AI_CHAT_HISTORY_TTL_SECS`.
- **Зависимости:** google-auth `add-token-exchange` (секрет `wallet-ai`),
  wallet-mcp `add-jwt-access`. Исходящий HTTPS к `api.anthropic.com` из
  контейнера wallet-ai (`ca-certificates` в образе уже есть).
- **Другие сервисы:**
  - wallet-gateway — без правок (`/api/ai/*` уже проксируется);
  - wallet-telegram — клиент (change `add-ai-chat`);
  - wallet-infra — переменные и сеть wallet-ai → wallet-mcp.
- **Приватность:** при выборе Claude результаты инструментов (суммы,
  категории, комментарии операций) уходят в Anthropic. Это включается
  только явным согласием пользователя.
- **Вне объёма:**
  - собственный ключ пользователя (вариант b);
  - веб-чат;
  - инструмент `draft_expense`;
  - стриминг ответа.
