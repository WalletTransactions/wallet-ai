# Design

## Context

- System-промпт задания `chat` — `prompts/chat.txt`, читается при старте
  (`llm::load_prompt`, `src/main.cpp`), версия пишется в журнал. В конец
  подставляются `instructions` wallet-mcp (`{mcp_instructions}`).
- wallet-mcp на неизвестное имя отвечает `isError` «"Алкоголь" не найдено.
  Есть: Alcohol, …» (полный список имён), на неоднозначное — «подходит к
  нескольким: …». Его `instructions` велят переспрашивать только во втором
  случае.
- `spending_by_category_by_month`: период не длиннее 36 месяцев,
  `months_of_year` — фильтр месяцев года, «остальные месяцы» — вторым вызовом
  с тем же периодом; `categories` и `exclude_categories` вместе — ошибка.
- `search_operations`: `text` — массив вариантов (любой из них), без
  `from`/`to` — вся история по сегодня; выдача — последние операции первыми,
  у каждой есть категория.
- Модель на test — gemma-4-e4b (`wallet-parse`, GTX 1070, контекст 8192).

## Goals / Non-Goals

**Goals:** три живых вопроса из задачи проходят на test без правок wallet-mcp.

**Non-Goals:** правка описаний инструментов wallet-mcp (отдельный change
wallet-mcp, «Workflow follow-up» `search-default-period`); смена модели.

## Decisions

- **D1. Только промпт.** Ошибки — в выборе аргументов моделью, инструменты
  отвечают верно (wallet-mcp 6.1, 4.1, 2.1 проверены curl). Правка кода
  цикла не нужна.
- **D2. Правило имён опирается на ответ «Есть: …».** В ошибке уже есть все
  имена, лишний вызов `list_categories` нужен, только если списка в ответе
  нет. Примеры перевода в промпте — «Алкоголь → Alcohol», «Няня → Baby
  Sitter»: реальные расхождения из живых прогонов (add-chat-agent 6.3).
- **D3. Период сравнения месяцев года по умолчанию — последние 24 полных
  месяца** (с 1-го числа того же месяца два года назад по последний день
  прошлого месяца). Тогда каждый месяц года попадает в расчёт дважды, а
  лимит 36 месяцев не нарушается. Вопрос «лето против остальных» без периода
  не переспрашивается: в chat-v2 «переспрашивай про период, только если он не
  назван совсем» дало ответ только за 2026 год.
- **D4. «Остальные месяцы» в промпте выписаны явно** — `[1,2,3,4,5,9,10,11,12]`
  для лета: модель 4–8B ошибается в дополнении списка.
- **D5. Поиск: примеры вариантов прямо в правиле** — «стриж», «парикмах»,
  «барбер», «barber», «haircut» (как в описании `search_operations`), и
  правило «купленный товар — не услуга»: при неоднозначном совпадении
  отвечать по операции, чья категория подходит по смыслу.
- **D6. Проверка — юнит-тест на опорные слова** (`exclude_categories`,
  `months_of_year`, `avg_per_month`, `list_categories`, `search_operations`)
  и версию `chat-v3`; качество — только живым прогоном (п. 3 tasks.md).
- **D7. Предел попыток.** Правило, не помогшее с двух живых попыток,
  записывается в tasks.md wallet-mcp как «качество модели», пункт
  закрывается (условие задачи).

## Risks / Trade-offs

- Длиннее промпт → больше токенов на шаг (~250 × до 6 шагов). На GTX 1070 —
  доли секунды на prefill, в пределах D11 add-chat-agent.
- Примеры из реального кошелька владельца могут «подсказывать» модели
  ответ. Приняли: это имена категорий, не суммы, и они в промпте только как
  иллюстрация перевода.
